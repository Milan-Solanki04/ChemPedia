About this site

An interactive periodic table of all 118 elements, with the data behind them open, the arithmetic shown, and every sentence written for this site rather than borrowed from somewhere else.

What is here

The table is the centre of the site and everything else is a way of looking at it from further off. Each element has a page carrying the around forty values its record holds — melting point, electron configuration, electronegativity, who found it and when — along with what the element is used for and where it is found. Four alternate colourings of the whole table turn it into a map of state, of orbital block, of electronegativity and of discovery date. There is a glossary of 440 terms, and a temperature converter.

Everything works without JavaScript. The table is rendered into the page rather than drawn by a script in the browser, so it is there when the page loads and it is still there if the script never runs. What JavaScript adds — search, filtering, keyboard movement through the grid, isolating one group — is added on top of a page that was already complete.

How it is built

No framework, no build step beyond a script that runs on Node, and no dependencies. The site is HTML, CSS and JavaScript that a browser runs directly. Pages are generated by a build script that reads an authored template, fills its markers from the data, and writes one file per route — so the hundred and eighteen element pages, the four table views, the eleven group pages and the four hundred and forty glossary terms are four families generated from the records rather than four hundred and forty files somebody had to keep in step.

Colour is held in one token layer and nothing else names a colour, so a palette change is one edit. The table's geometry, its arrow-key movement and its colour scales are pure functions with unit tests; the parts that touch the DOM are verified in a browser instead, because that is the only way to see them.

Data sources

The numbers come from openly licensed structured datasets; the writing is ours. Each element record carries where its facts came from, and this table is counted from those records rather than maintained by hand, so it cannot drift from the data it describes.
