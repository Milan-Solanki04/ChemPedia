Contact

Corrections to the data are the most useful thing anyone can send. Everything else is welcome, and most of it can be found somewhere on the site.

What to write about

A figure that looks wrong

Say which element and which property, and give a source if you have one. Several values on this site are genuinely disputed — the electronegativity of astatine is calculated rather than measured, and some melting points are estimates from a compound rather than from the element — and where that is the case the page says so. If you think a value is presented as settled when it should be marked as uncertain, that is worth saying too.

Something on a page that reads badly

Every explanation here was written for this site, and a sentence that is unclear or wrong is a defect rather than a matter of taste. Which page, and which sentence, is all the detail needed.

Reusing the data or the writing

The element data comes from openly licensed datasets and the explanations are ours, and the about page records which is which and under what licence. If you want to use either, read that first; if your question is about permissions, that is what the answer is drawn from.

Something else

A bug in the table, a correction to the glossary, a suggestion for a term that is missing — all welcome. What is not useful is a request for the site to be extended in a particular direction without saying why, or an offer of reciprocal links.

Where to write

This address is a placeholder. The site is built but not yet published at a real domain, so mail sent here will not arrive. Saying so plainly is better than shipping an address that silently bounces.

Until it is live, the most useful thing you can do with a correction is to note it against the repository: every page on this site is generated from files in it, and the data and the prose are both plain text that can be read without running anything.
